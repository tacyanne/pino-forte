# Pino de Balança

Sistema de gestão de ordens de serviço, clientes, catálogo de pinos, pagamentos, carteira e relatórios.

## Funcionalidades

- Cadastro e gestão de clientes
- Catálogo de pinos e preços
- Emissão e acompanhamento de ordens de serviço
- Pagamentos à vista, parciais e por carteira
- Geração de PDF e envio ao cliente
- Painel financeiro e relatórios

## Tecnologia

Aplicação full-stack em TypeScript, React, Vinext, Cloudflare Workers, D1 e Drizzle ORM.

## Execução local

Requer Node.js 22.13 ou superior.

```bash
npm ci
npm run dev
```
